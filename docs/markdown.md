# 标题
如你所见头上那东西就是标题，只需要在段首加“#”就可以控制大小，“#”越多，放大倍数越小，用来表示类似树的结构
# 加粗与斜体
两个“ * ”包围的部分会被加粗你可以认为是爆粗口了，单个“ * ”表示斜体，显然一起就是加粗且斜体，因为都是“ * ”，所以一起讲
# 删除线
~~两个“～”包围的部分会被删除线盖住，是的就像这部分~~，通常可以用来表达一些不好直接说的内容
# 代码块
```
无需多言，两行由“```”包围的段落可以显示代码块
printf("Hello world!");
```
--------
`行内代码块只需要用单个字符在语句两侧即可`
# 列表
### 无序列表
用" - ", " * " 或" + "回车即可，以小圆点显示
### 有序列表
用数字+“.”回车，有意思的是编辑的数字本身不必有序，甚至可以重复
1. 
2. 
 比如这2行都是“1.”
# 表格
| 工具名称 | 用途 | 危险等级 |
| :--- | :---: | ---: |
| Nmap | 端口扫描 | 低 |
| Burp Suite | Web抓包 | 中 |
| SQLMap | 注入测试 | 高 |
_`:` 用于控制对齐，`:---` 左对齐，`:---:` 居中，`---:` 右对齐_
# 分割线
用三个或以上的 `-` 或 `*` 产生一条水平线
