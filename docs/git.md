# Git 常用命令

## 一、 配置与初始化

| 命令                                      | 作用                    |
| :-------------------------------------- | :-------------------- |
| `git init`                              | 在当前目录初始化一个新的本地 Git 仓库 |
| `git clone <url>`                       | 克隆远程仓库到本地             |
| `git config --global user.name "你的名字"`  | 配置全局用户名               |
| `git config --global user.email "你的邮箱"` | 配置全局邮箱                |

## 二、 状态与查看

| 命令                          | 作用                                   |
| :-------------------------- | :----------------------------------- |
| `git status`                | 查看当前工作区和暂存区的状态                       |
| `git diff`                  | 查看尚未暂存的文件变更内容                        |
| `git log --oneline --graph` | 以单行、图形化方式查看提交历史                      |
| `git reflog`                | 查看所有分支的所有操作记录（包括被删除的 commit，**后悔药**） |

## 三、 提交代码 (Add & Commit)

| 命令                     | 作用                      |
| :--------------------- | :---------------------- |
| `git add <文件名>`        | 将指定文件添加到暂存区             |
| `git add .`            | 将当前目录下所有变更添加到暂存区        |
| `git commit -m "提交说明"` | 将暂存区的内容提交到本地仓库          |
| `git commit --amend`   | 修改最近一次的提交（可改说明或补充漏掉的文件） |

## 四、 分支管理 (Branch)

| 命令                      | 作用          |
| :---------------------- | :---------- |
| `git branch`            | 查看本地分支      |
| `git branch <分支名>`      | 创建新分支       |
| `git switch <分支名>`      | 切换到指定分支     |
| `git checkout -b <分支名>` | 创建并立即切换到新分支 |
| `git branch -d <分支名>`   | 删除已合并的分支    |
| `git branch -D <分支名>`   | 强制删除未合并的分支  |

## 五、 远程同步 (Remote)

| 命令                         | 作用               |
| :------------------------- | :--------------- |
| `git remote -v`            | 查看当前关联的远程仓库地址    |
| `git pull`                 | 拉取远程代码并自动合并到当前分支 |
| `git push`                 | 将本地提交推送到远程仓库     |
| `git push -u origin <分支名>` | 首次推送新分支，并建立追踪关系  |
|                            |                  |

## 六、 撤销与回退

| 命令                           | 作用                             |
| :--------------------------- | :----------------------------- |
| `git restore <文件名>`          | 丢弃工作区中未暂存的修改                   |
| `git restore --staged <文件名>` | 将文件从暂存区撤出（撤销 `git add`）        |
| `git reset --soft HEAD~1`    | 撤销最近一次 commit，保留代码修改在暂存区       |
| `git reset --hard HEAD~1`    | **危险**：撤销最近一次 commit，并彻底丢弃代码修改 |

## 七、 合并与冲突 (Merge & Rebase)

| 命令 | 作用 |
| :--- | :--- |
| `git merge <分支名>` | 将指定分支合并到当前分支 |
| `git rebase <分支名>` | 变基（让提交历史变成一条直线，比 merge 更干净） |
| `git stash` | 将当前未提交的修改“储藏”起来，让工作区变干净 |
| `git stash pop` | 恢复最近一次储藏的内容，并从 stash 列表中删除 |

## `git cherry-pick` (拣选)
将其他分支上的某一个特定的提交，单独“摘”下来，应用到你当前分支。
```
git switch main
git cherry-pick <commit-hash>       # 摘取单个提交
git cherry-pick -n <commit-hash>    # 摘取但不自动提交
git cherry-pick --abort             
```
